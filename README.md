# HTML5 e CSS3

Repositório criado para reunir meus estudos, exercícios, desafios e projetos desenvolvidos durante o curso de HTML5 e CSS3 do Curso em Vídeo, ministrado por Gustavo Guanabara.

O conteúdo está organizado de acordo com os módulos estudados ao longo do curso, registrando minha evolução no desenvolvimento de páginas web.

## Sobre o repositório

Este repositório funciona como um registro do meu processo de aprendizagem em desenvolvimento Front-End, reunindo diferentes exercícios práticos realizados durante o curso.

Os estudos abordam desde os fundamentos de HTML até conceitos mais avançados de CSS e desenvolvimento de páginas responsivas.

## Organização

O conteúdo está dividido em módulos:
* M1 | Fundamentos de HTML e CSS
* M2 |	Estruturação e estilização de páginas
* M3	| Responsividade e recursos avançados
* M4	| Projetos e aplicação dos conceitos

## Tecnologias
* HTML5
* CSS3
